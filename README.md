# じっと教大戦争

React + TypeScript + Vite / Canvas製、1ステージ完結のタワーディフェンス。
外部API・サーバー・認証は不要です。Node.js 22.18以上（動作確認: 24）を使用してください。

## 起動と検証

```sh
npm ci --cache /tmp/tower-npm-cache
npm run dev
```

```sh
npm test        # 出撃制限、停止、敵出現、敗北、混成軍での勝利、範囲攻撃
npm run build   # 型チェックと本番ビルド
npm run preview # distの確認
```

ホームの「編成を変更」で既存4種類を10枠に配置・移動・解除できます。重複は不可、1体以上で出陣できます。
「岩の聖地へ出陣」→「出陣する」で開始。下部の10枠のカードを押すと編成したキャラを出撃できます。空き枠は出撃不可です。
リトライは同じ編成で再戦。「撤退してホーム」で戦闘を終了して戻ります。
編成は画面移動中のみ保持し、ページ更新後の永続保存はPhase 3で実装予定です。
資金は毎秒30円増加し、敵撃破で25円獲得。上限は1,800円です。
味方は自動で前進・攻撃し、敵の砦のHPを0にすると勝利。総本山のHPが0になると敗北です。
一時停止・再開・リトライができ、別タブに移ると自動で一時停止します。
スマートフォンでは戦場を左右にスワイプできます。
序盤から見習い信者で後衛を守り、大型への貯金と前線の補充を両立させよう。大型だけでは突破できません。
次の襲来表示で出現時刻と対策を確認できます。狙撃兵には壁役、密集を狙う破戒砲兵には遠距離攻撃が有効です。
出撃可能なカードは明るい枠と「出撃可能」で表示。資金不足時は不足額、クールタイム中は残り秒数を表示します。
攻撃には最大45msのヒットストップ、衝撃波、戦場内の振動、被弾反動・撃破時の吹き飛びがあります。
ヒットストップ中も資金・クールタイムと出撃操作は進みます。振動はOSの「視差効果を減らす」設定で停止します。

## 調整と顔素材の差し替え

- `src/data.ts`: 4種類の味方・5種類の敵の能力、コスト、再出撃時間、ステージ・出現時刻。
- `src/engine.ts`: 描画に依存しない戦闘ロジック。時間の単位は秒。
- `src/render.ts`: 戦場・敵のCanvas描画とダメージ表示。
- `src/characterSprites.ts` / `src/characterAssets.ts`: 全身画像の共通設定・戦闘アニメーション。
- `src/CharacterImage.tsx`: 既存・将来の画面で使う共通画像表示。
- `src/characterArt.ts`: 画像欠落時のみ使う旧描画。
- `public/characters/`: キャラ別の独立PNG。`src/assets/ally-faces.png` は旧描画のフォールバック用。
- `src/main.tsx`: ホームと編成画面、画面移動とセッション内の編成状態。
- `src/formation.ts`: 10枠の正規化・移動・解除。
- `src/BattleScreen.tsx` / `src/Portrait.tsx` / `src/style.css`: 戦闘UI・共通キャラ表示・レスポンシブ表示。

味方は `public/characters/` の個別画像で描画します。見習い・拳僧・魔導士は透過PNG、けいとは `iwason/` 内の提供された背景付き仮素材セットを使用します。
けいとは待機・移動・攻撃・被弾・撃破を状態別フレームで切り替えます。[素材セットの組み込み・透過素材への差し替え](public/characters/iwason/INTEGRATION.md) を参照してください。
通常表示は旧来の顔アトラスやCanvas衣装合成を使いません。画像が読み込めない場合だけ旧描画へ戻ります。
同名ファイルの置き換えだけで既存の全画面に反映でき、縦横比と全身表示を維持します。
WebPへの変更と共通表示部品の使い方は [キャラクター画像の説明](public/characters/README.md) を参照してください。
強化・ガチャの新機能は未実装ですが、共通表示部品を利用できる構造です。

## GitHub Pages

`npm run build` の `dist/` を配信できます。Viteのbaseは相対パスです。
同梱ワークフローは `main` へのpushまたは手動実行でテスト・ビルドし、Pagesへ配置します。
GitHubの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。
リポジトリ設定やPages公開操作はこの実装では実行していません。

## UI

ホームの大型キャラ・アイコンメニュー、コンパクトな戦闘HUD、顔アップの10枠出撃ドックを採用しています。
出撃可能・資金不足・クールタイムを光・色・ラベルで区別します。
共通デザインと描画サイズの方針は [UI_DESIGN.md](UI_DESIGN.md) を参照してください。
