# ユーザー提供：岩尊けいと素材セット

`iwason_sprite_assets.zip` の全16画像と `README.json` を、内容を変えずに格納しています。
README.jsonは素材に付属する説明データです。セット内画像は**背景・ラベル・別ポーズの写り込みが残る仮素材**であり、完成透過素材として扱いません。
背景除去・画像再生成・元画像の切り抜き加工は行っていません。

## 使用箇所

| ファイル                         | 用途                             | 再生                    |
| -------------------------------- | -------------------------------- | ----------------------- |
| `portrait.png`                   | ホーム・編成・出撃枠の共通立ち絵 | 静止                    |
| `idle_01.png`〜`idle_04.png`     | 戦闘中の待機                     | 4fpsループ              |
| `walk_01.png`〜`walk_04.png`     | 位置変化があるときの移動         | 8fpsループ              |
| `attack_01.png`〜`attack_03.png` | 攻撃中                           | 10fps・最後のコマで停止 |
| `hit_01.png`・`hit_02.png`       | 被弾中                           | 12fps・最後のコマで停止 |
| `death.png`                      | HPが0になった後                  | 撃破時間中のフェード    |
| `special.png`                    | 今後の演出用として保存           | 今回は未使用            |

強化画面はまだ未実装です。追加時は `CharacterImage` を使えば同じ `portrait.png` を表示できます。
`portrait.png` に含まれる下部の別ポーズや「被弾」の文字も、元データのまま表示されます。

## 共有する仕組み

`src/characterAssets.ts` の `keito` 定義に画像パス、仮素材の品質区分、各状態のフレーム、fps・ループ、基準寸法を設定します。
他キャラにも同じ `clips` を追加できます。状態別画像がないキャラはこれまでの1枚絵を使います。

状態の優先順位は **撃破 → 被弾 → 攻撃 → 移動 → 待機**。
攻撃・被弾・撃破の時間は既存エンジンの `pose`・`flash`・`dead` を読み取り、変更しません。
待機と移動は戦闘時間を参照するため、一時停止中はフレームも停止します。

描画の縦横比は維持します。異なる寸法のフレームを、310×255pxの共通キャンバスへ足元・中央基準で配置するため、各状態へ切り替わっても画像そのものの縮尺は一定です。
フレームは事前読込・キャッシュします。特定フレームが欠落している場合は立ち絵へ戻し、立ち絵も読めない場合だけ旧描画へ戻ります。

## 透過素材への差し替え

1. 同じファイル名の透過PNGに置き換え、ページを更新します。
2. 全フレームで元のピクセル縮尺・足元・余白を揃えるか、描き直したサイズに合わせて `frameCanvas` を調整します。
3. 別名やWebPにする場合は画像パスも更新します。ポーズ数が変わる場合は `frames` と `fps` を更新します。
4. 背景・ラベルが除去され完成素材になった段階で、`quality` を `production` に変更します。現在は `draft-background` です。

旧生成素材 `../keito.png` は元ファイルとして残していますが、現在のけいとの通常表示はこのフォルダの素材を優先します。
