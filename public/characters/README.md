# 全身キャラクター画像

通常描画用の独立画像を管理します。見習い・拳僧・魔導士は生成した架空キャラの透過PNG、けいとはユーザー提供の背景付き仮素材です。
顔・衣装・武器・足・オーラを含む**全身の1枚絵**であり、旧顔アトラスは使いません。

| キャラクター | 必須ファイル名 |
| ------------ | -------------- |
| 見習い信者   | `novice.png`   |
| 岩の拳僧     | `monk.png`     |
| ドラクエ信者 | `mage.png`     |
| 岩尊けいと   | `iwason/portrait.png`（提供仮素材） |
| 鐘守りの巡礼 | `bellkeeper.svg`（専用仮素材） |

## 差し替え

同じファイル名で画像を置き換え、ページを更新すると、ホーム・編成・強化・ガチャ・図鑑・出撃枠・戦闘へ反映されます。
けいとの状態別フレームと差し替え方法は [素材セットの組み込み](iwason/INTEGRATION.md) を参照してください。
実際のURLは `./characters/novice.png` 等です。GitHub Pagesのサブディレクトリにも対応します。
画像は頭・武器・足が収まる透過PNGまたはWebPにしてください。
WebPを使う場合は `src/characterAssets.ts` の該当 `image` パスを変更します。
縦横比はUIの `object-fit: contain` と戦闘の `containSize` で維持し、画像自体は切り抜きません。
極端に大きな余白を画像に含めるとキャラが小さくなるため、全身の周囲に5〜10%程度の余白を推奨します。

## 共通表示の入口

- `src/characterAssets.ts`: 全キャラの画像パス・戦闘での最大表示寸法・アニメーション係数。
- `src/CharacterImage.tsx`: ホーム・編成・強化・ガチャ・図鑑・出撃枠が使う共通UI部品。
- `src/characterImages.ts`: CanvasとUIで共通の読み込み状態とキャッシュ。
- `src/characterSprites.ts`: 読み込んだ全身画像を移動・攻撃・被弾・撃破時に動かす。`clips` があれば状態別のコマを切り替え、なければ単体画像の移動・回転・等比拡縮・明度・フェードで動かす。

画像の404・破損など、読込失敗を確認した場合だけ、既存の手続き的キャラ描画へ戻ります。
読み込み待ちの間は旧キャラを表示しません。
強化画面でもこの共通画像を使用します。ガチャはまだ未実装です。

## ガチャ追加キャラ

鐘守りの巡礼は色違いではなく、石面・巡礼服・巨大な鐘を持つ独立したオリジナルSVG仮素材です。`quality: "placeholder"` を設定しています。
専用PNG/WebPを用意したら `characterAssets.ts` の `bellkeeper.image` と表示枠を調整してください。戦闘アニメーション・全画面に同じ設定が反映されます。
岩尊の提供画像の背景・ラベル・別ポーズは保持しています。今回透過加工や画像の再生成はしていません。
