# 全身キャラクター画像

通常描画に使う、ゲーム用に生成した架空キャラクターの独立した透過PNGです。
顔・衣装・武器・足・オーラを含む**全身の1枚絵**であり、旧顔アトラスは使いません。

| キャラクター | 必須ファイル名 |
| ------------ | -------------- |
| 見習い信者   | `novice.png`   |
| 岩の拳僧     | `monk.png`     |
| ドラクエ信者 | `mage.png`     |
| 岩尊けいと   | `keito.png`    |

## 差し替え

同じファイル名で画像を置き換え、ページを更新すると、ホーム・編成・出撃枠・戦闘へ反映されます。
実際のURLは `./characters/novice.png` 等です。GitHub Pagesのサブディレクトリにも対応します。
画像は頭・武器・足が収まる透過PNGまたはWebPにしてください。
WebPを使う場合は `src/characterAssets.ts` の該当 `image` パスを変更します。
縦横比はUIの `object-fit: contain` と戦闘の `containSize` で維持し、画像自体は切り抜きません。
極端に大きな余白を画像に含めるとキャラが小さくなるため、全身の周囲に5〜10%程度の余白を推奨します。

## 共通表示の入口

- `src/characterAssets.ts`: 全キャラの画像パス・戦闘での最大表示寸法・アニメーション係数。
- `src/CharacterImage.tsx`: ホーム・編成・出撃枠が使う共通UI部品。今後の強化・ガチャもこの部品を使う。
- `src/characterImages.ts`: CanvasとUIで共通の読み込み状態とキャッシュ。
- `src/characterSprites.ts`: 読み込んだ全身画像を移動・攻撃・被弾・撃破時に動かす。単体PNGを移動・回転・等比拡縮・明度・フェードでアニメーションする方式で、コマ別の手描きスプライトアニメーションではない。

画像の404・破損など、読込失敗を確認した場合だけ、既存の手続き的キャラ描画へ戻ります。
読み込み待ちの間は旧キャラを表示しません。
強化・ガチャは未実装のままで、今回追加したのは表示の共通化だけです。
