# 岩石軍団の画像アセット

全30体を共通の `CharacterImage` / Canvas画像描画で表示します。岩尊けいとだけ既存の提供画像と全状態クリップを維持し、他29体をそれぞれ独立した専用SVGへ変更しました。

**29体はオリジナルのSVG仮素材です。実写風の完成画像を生成したものではありません。** 大きな架空の彫刻顔・小さい鉱石の体を配置し、体型・衣装・武器・顔型を描き分けています。本人写真や実在人物の顔は使用していません。

- 通常の素材：`public/characters/rock-army/{キャラID}.svg`、透過、`viewBox="0 0 360 420"`。
- 岩尊：`public/characters/iwason/portrait.png` と同ディレクトリの状態別クリップ。背景・ラベルが残る仮素材です。
- 既存の `novice.png` / `monk.png` / `mage.png` / `bellkeeper.svg` 等は削除せず残しています。通常表示では新しい岩石軍団SVGを優先します。

詳細一覧と再生成方法は [rock-army/README.md](rock-army/README.md)、岩尊の提供素材は [組み込みと差し替え](iwason/INTEGRATION.md) を参照してください。

## 差し替え

`src/characterAssets.ts` が全画面の画像パス・表示寸法・モーション設定を一元管理します。
キャラごとの `image` を独立PNG/WebPのパスへ変更すると、編成・強化・ガチャ・図鑑・出撃枠・戦闘へ反映されます。岩尊の既存パスとクリップは変更していません。

画像は顔・武器・足・オーラを含む全身を収め、周囲に5〜10%の余白を設けてください。
UIでは `object-fit: contain`、戦闘では `containSize` で縦横比を維持し、切り抜き・縦横の引き伸ばしは行いません。
GitHub Pages配下でも動作する相対パスを使用してください。完成素材に差し替えたら `quality` を `production` に変更できます。

## モーションと共通部品

- `src/characterAssets.ts`: 全キャラの独立パス・表示枠・素材品質・移動/攻撃プロファイル。
- `src/CharacterImage.tsx`: 全UI共通の全身表示。仮素材はデータ属性とタイトルで明示。
- `src/characterImages.ts`: UI/Canvas共通の読込キャッシュ。失敗画像の再試行ループを防止。
- `src/characterSprites.ts`: 等比表示、歩行・呼吸・攻撃・被弾反応・撃破時の吹き飛び。

移動は歩行・重量歩行・浮遊・転がり、攻撃は突進・反動・詠唱・回転・叩きつけを共通プロファイルとして使います。見た目はキャラ別の独立SVGであり、共通の卵型の色替えではありません。
状態別の完成PNGを用意した場合は、岩尊と同じ `clips` に待機・移動・攻撃・被弾・撃破を設定できます。
読み込み待ちで旧キャラへ戻さず、確認済みの404・破損時だけフォールバックを使用します。
