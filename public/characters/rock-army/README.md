# 岩石軍団 SVG 仮素材

このディレクトリは29体の独立したオリジナルSVG立ち絵です。岩尊けいとはここへ移さず、既存の提供素材を維持しています。

完成した実写風画像ではありません。顔は陰影と顔面の面・目鼻口・皺・傷・彫刻髪を持つ仮イラストです。写真の本人再現・背景除去・外部素材の流用は行っていません。
全身は透過SVGで、体格（盾兵・転石輪・浮石・砲台・長い岩龍・重い巨人等）と、衣装・武器・姿勢を描き分けています。

## 再生成

プロジェクトのルートから `python3 scripts/generate-rock-assets.py`。
外部ライブラリ・ネットワーク・画像生成APIは使用しません。実行するとこのディレクトリ内の29 SVGを再生成・上書きします。
各キャラの体型・武器・固有表現は生成器のキャラ定義、顔の形状や材質は共通ヘルパーで管理します。キャラごとにゲーム描画コードを複製する必要はありません。

完成したPNG/WebPを別ファイルとして配置し、`src/characterAssets.ts` の対象キャラの `image` だけを変更すれば、全画面・戦闘へ反映できます。
SVGのまま独自に描き直した素材を維持する場合は、生成器を再実行する前に別ファイルへ退避してください。

## 仮素材の制限

- 実写風の顔・高品質な鉱石テクスチャの本素材は未制作です。
- 29体は立ち絵1枚＋共通変形モーションです。手足ごとの関節や専用の連番画像はありません。
- 岩尊の提供画像と全クリップは変更していません。
- 29体それぞれ専用のパスとSVGファイルを持つため、後から1体ずつ置き換えられます。
