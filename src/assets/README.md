# 旧描画用の顔素材（フォールバック限定）

通常の味方描画は `public/characters/` のキャラ別全身画像を使用します。
このフォルダの顔アトラスと `portrait` 指定は、全身画像が読み込めないときの旧描画用です。
通常画像の差し替えは [全身画像の説明](../../public/characters/README.md) を参照してください。

# 味方キャラクターの仮素材

`ally-faces.png` はこのゲーム用に生成した、架空の4人の顔の透過アトラスです。
1254×1254px、2×2配置。左上=見習い、右上=拳僧、左下=魔導士、右下=けいと。
けいとはユーザー提供の岩の巨人の参考画像から、岩の質感・力強い顔立ちを参考にしています。
本人写真の代用として特定の実在人物を再現したものではありません。

衣装や武器はこの画像に焼き込まず、`src/characterArt.ts` のCanvas描画で別に構築しています。
顔・衣装・武器・腕・足・魔法陣を動かすため、1枚絵の平行移動だけにはなりません。
敵キャラクターの描画は今回変更していません。

## 顔の差し替え

1. 背景を透過した頭部の写真を `public/portraits/` に配置する。
2. `src/data.ts` の該当キャラへ `portrait: './portraits/novice.png'` のように追加する。
3. 必要なら `CHARACTER_ART` の `box`（左・上・幅・高さ）と `eyes`（目の縦位置）を調整する。

`portrait` が指定されると、その画像全体を顔として描画し、既定アトラスは使いません。
画像読込完了後にホーム・編成・出撃枠も再描画します。URLはGitHub Pages用に相対パスを推奨。
差し替え画像が読めない場合は専用輪郭の簡易顔へフォールバックします。

## 動き

- 待機: 呼吸、瞬き。見習いは首をかしげ、魔導士は上下に浮遊。
- 移動: 見習いの小刻みな足運び、拳僧の踏み足、魔導士の浮遊、けいとの重い歩行。
- 攻撃: 合掌からの押し出し、岩拳の突き出し、杖と魔法陣、岩鎧と後光の衝撃波。
- 被弾: 顔の回転・潰れ・明度変化、体の反動。見習いは汗を飛ばす。
- 撃破: 弧を描く吹き飛び・回転・目を閉じる・星とフェード。

移動の判定は描画側のWeakMapで位置変化を観測します。戦闘エンジンや能力値を変更しません。
戦闘時間を使うため、一時停止中はアニメーションも停止します。
